# Copilot Agent Demo

A simple Python banking application that demonstrates core account operations:

- Deposit money into an account
- Withdraw money from an account
- Transfer money between accounts
- Raise `InsufficientFundsError` when a withdrawal or transfer exceeds the available balance

## Run the application

```bash
python main.py
```

The example creates two accounts, deposits money, performs a transfer, and prints the resulting balances.
